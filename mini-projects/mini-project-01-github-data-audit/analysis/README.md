# Analysis workspace

Place reproducible working files here, such as Excel workbooks, Power Query steps, notebooks, scripts, validation tables, and supporting figures.

## Minimum expectations

- Preserve the original file in `data/raw/`.
- Store cleaned data separately.
- Make every report number traceable to an analysis file.
- Document assumptions and transformations.
- Use descriptive file names and meaningful Git commits.
- Do not commit temporary files, credentials, or restricted information.
